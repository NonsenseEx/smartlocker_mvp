# SmartLocker MVP - Gestión de Préstamo de Equipos

Proyecto desarrollado para la asignatura de Ingeniería de Software (TI3043) de INACAP. 
SmartLocker es un Producto Mínimo Viable (MVP) que automatiza el control de inventario y el préstamo de equipos tecnológicos en el pañol universitario, aplicando reglas de negocio como la validación de stock y el bloqueo de usuarios sancionados.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python 3
* **Framework:** Django (Patrón de arquitectura MVT)
* **Base de Datos:** SQLite (Entorno de desarrollo)
* **Frontend:** HTML5, CSS3 y Bootstrap 5
* **Control de Versiones:** Git y GitHub
